# Шпаргалка лектора: Глава 2. Провайдери баз даних

> **Важливо перед початком глави:** у цьому навчальному солушені всі приклади запускаються «з коробки» на **SQLite**, щоб не вимагати розгорнутих серверів SQL Server / MySQL / PostgreSQL. Оригінальні рядки підключення та методи `UseSqlServer` / `UseMySql` / `UseNpgsql` наведено в коментарях коду та в `.md`-конспектах.

## План проведення та запуски

| ID | Тема та конспект | Про що говорити (ключові тези) | Команда запуску та CLI | На що звернути увагу у виводі |
|---|---|---|---|---|
| **7.1** | [Провайдер MS SQL Server](7_01_SqlServerProvider.md) · [код](../../src/02_DatabaseProviders/Lesson_7_01_SqlServerProvider.cs) | • Офіційний провайдер від Microsoft (`Microsoft.EntityFrameworkCore.SqlServer`).<br>• Підключення до LocalDB (`(localdb)\mssqllocaldb`), SQL Express (`.\SQLEXPRESS`) та повноцінного сервера.<br>• Параметри `Trusted_Connection=True` vs SQL-автентифікація, нюанс із `TrustServerCertificate=True` у нових `Microsoft.Data.SqlClient`.<br>• Перевага передачі `DbContextOptions<T>` — легка заміна провайдера без переписування бізнес-логіки. | `dotnet run --project src/EFCoreMastery.ConsoleApp -- 7.1`<br><br>*(NuGet для реального SQL Server)*:<br>`dotnet add package Microsoft.EntityFrameworkCore.SqlServer` | • Ім'я провайдера та згенерований SQL через `ToQueryString()`.<br>• Пояснити відмінність типів стовпців: `NVARCHAR(MAX)` + `IDENTITY(1,1)` у SQL Server vs `TEXT` + `AUTOINCREMENT` у SQLite. |
| **7.2** | [Провайдер MySQL](7_02_MySqlProvider.md) · [код](../../src/02_DatabaseProviders/Lesson_7_02_MySqlProvider.cs) | • Два популярні провайдери: **Pomelo.EntityFrameworkCore.MySql** (найпопулярніший у спільноті) та офіційний `MySql.EntityFrameworkCore` від Oracle.<br>• Особливість Pomelo: обов'язкова передача версії сервера `ServerVersion.AutoDetect(connStr)` або `new MySqlServerVersion(...)`.<br>• Параметри рядка підключення: `server`, `user`, `password`, `database`, `port`. | `dotnet run --project src/EFCoreMastery.ConsoleApp -- 7.2`<br><br>*(NuGet для реального MySQL)*:<br>`dotnet add package Pomelo.EntityFrameworkCore.MySql` | • Вивід `ToQueryString()` та синтаксис екранування ідентифікаторів: зворотні лапки `` `Users` `` у MySQL проти подвійних `"Users"` у SQLite.<br>• Пояснити ризик `AutoDetect()` при недоступній БД на старті (краще фіксувати версію у проді). |
| **7.3** | [Провайдер PostgreSQL](7_03_PostgreSqlProvider.md) · [код](../../src/02_DatabaseProviders/Lesson_7_03_PostgreSqlProvider.cs) | • Основний провайдер: **Npgsql.EntityFrameworkCore.PostgreSQL**.<br>• Особливості PostgreSQL: регістрозалежність ідентифікаторів у подвійних лапках (`"Users"`), `GENERATED BY DEFAULT AS IDENTITY`, нативна підтримка JSONB, масивів та `DateTime` (UTC).<br>• Формат рядка підключення: `Host=...;Port=5432;Database=...;Username=...;Password=...`. | `dotnet run --project src/EFCoreMastery.ConsoleApp -- 7.3`<br><br>*(NuGet для реального PostgreSQL)*:<br>`dotnet add package Npgsql.EntityFrameworkCore.PostgreSQL` | • Секція порівняння згенерованого SQL (SQLite і PostgreSQL дуже близькі за ANSI-лапками `""`, але відрізняються типами даних та `LIMIT`/`OFFSET`). |

## Зведена шпаргалка провайдерів (для дошки / слайда)

| СУБД | NuGet-пакет | Метод `DbContextOptionsBuilder` | Приклад рядка підключення |
|---|---|---|---|
| **SQLite** *(використовується в курсі)* | `Microsoft.EntityFrameworkCore.Sqlite` | `UseSqlite(connStr)` | `Data Source=app.db` |
| **MS SQL Server** | `Microsoft.EntityFrameworkCore.SqlServer` | `UseSqlServer(connStr)` | `Server=(localdb)\mssqllocaldb;Database=appdb;Trusted_Connection=True;TrustServerCertificate=True;` |
| **MySQL / MariaDB** | `Pomelo.EntityFrameworkCore.MySql` | `UseMySql(connStr, new MySqlServerVersion(...))` | `server=localhost;user=root;password=pass;database=appdb;` |
| **PostgreSQL** | `Npgsql.EntityFrameworkCore.PostgreSQL` | `UseNpgsql(connStr)` | `Host=localhost;Port=5432;Database=appdb;Username=postgres;Password=pass` |
