# Шпаргалка лектора: Глава 3. Створення моделей в EF Core

> **Фокус глави:** як C#-класи перетворюються на таблиці, стовпці, ключі, індекси та обмеження в БД. Протягом усієї глави наголошуйте на трьох рівнях пріоритету конфігурації: **Угоди (Conventions) → Анотації даних (Data Annotations) → Fluent API (найвищий пріоритет)**.
